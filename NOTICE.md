# Provenance

Grain Photo is a separate implementation prepared for the user who supplied their Zircon Cinema repository (`https://github.com/astanabesta/camera`). Its Camera2 request approach was inspected and adapted for a new still-photo engine. The existing app's source/media files are not bundled in this project and its video implementation is not imported wholesale.

Android and Java APIs, Gradle, Android Gradle Plugin and AndroidX ExifInterface are used under their respective licenses. No MotionCam source or third-party `.cube` assets are included. Choose an appropriate project license before public redistribution; no license grant over the user's existing repository is invented here.

The HTML design reference contains AI-generated sample photography and demonstrates interface behavior only. The Android app uses the real device camera and does not use that photo as a camera preview.
